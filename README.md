## 🎯 What is AI Debate Arena?

**AI Debate Arena** is an advanced multi-agent system where two sophisticated AI agents engage in structured debates on user-defined topics. The user acts as the **judge**, analyzing argument strength, logical consistency, and persuasive power to declare the winner.

### 🧠 Think of it as:
> *ChatGPT vs DeepSeek in a logical gladiator match — where YOU decide who wins!*

---

## ✨ Key Features

| Feature | Description |
|---------|-------------|
| 🤖 **Multi-AI Agents** | Two specialized AI agents with unique debate styles |
| 🎭 **Opposing Viewpoints** | Pro vs Con structured arguments |
| 🔄 **Turn-Based Flow** | Opening arguments → Rebuttals → Final statements |
| 📊 **Argument Strength Analysis** | Real-time scoring of logic, evidence, persuasion |
| 👑 **User as Judge** | You decide the winner based on argument quality |
| 📝 **Debate Summary** | Auto-generated recap of the entire debate |
| 🎨 **Visual Animations** | Engaging UI with typing effects and transitions |
| 📈 **Performance Stats** | Track agent win rates and argument quality |
